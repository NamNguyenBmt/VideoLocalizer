Nhân bản giọng từ mẫu (F5-TTS)

Clone cần pip install f5-tts (khuyến nghị GPU). Giọng clone dùng được trong tab Xử lý: chọn engine Clone + điền đường dẫn giọng mẫu.

Sửa phụ đề (SRT)

Sửa xong bấm Lưu, rồi "Dùng SRT này" → sang tab Xử lý (Lấy lời thoại = Dùng SRT có sẵn) để render/lồng tiếng theo bản đã sửa.
